# Sistema Agéntico de BUMAND (Antigravity IDE)

Esta carpeta define el comportamiento del sistema guiado por Inteligencia Artificial (Google Antigravity) para el mantenimiento y migración del ecosistema BUMAND. 

## Estructura
- `rules/`: Contiene las directrices inflexibles de arquitectura (Nest.js, Next.js, Flutter), flujos de trabajo (npm run compilar) y convenciones de código (Español, camelCase/PascalCase) que el agente DEBE seguir incondicionalmente.
- `skills/`: Contiene habilidades especializadas invocables (generador de PDFs, diseño avanzado de UI) que asisten en la ejecución de tareas específicas.
- `BACKLOG_GENERAL.md` y `BACKLOG_TEMPORAL.md`: Documentos activos donde el agente rastrea el progreso global del proyecto y las metas iterativas inmediatas.

Al iniciar cualquier tarea, el agente cargará automáticamente este contexto para asegurar calidad empresarial e higiene de código en cada interacción.
